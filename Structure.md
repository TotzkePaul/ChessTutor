# Project structure — ChessTutor

This file documents the repository layout and what each major file/folder is responsible for. It should help new contributors and make it easier to triage bugs.

Top-level

- `package.json` — project scripts and dependencies.
- `README.md` — (project readme) general info.
- `public/` — static HTML and assets used by the app.
- `build/` — production build artifacts (generated by `npm run build`).
- `src/` — application source code (React app).

Key `src/` folders and files

- `src/index.js` — app bootstrap and ReactDOM render.
- `src/App.js` — top-level app component and routing/wiring.
- `src/components/` — UI components used by the app:
  - `AiControls.js` — controls for the AI (difficulty, start/stop AI moves).
  - `Board.js` — board layout and top-level board render logic. Likely a central place to check for rendering bugs.
  - `Square.js` — individual square rendering; check for event handlers and props.
  - `MoveHistory.js` — renders move list and undo/redo if implemented.
  - `StrategySelector.js` — UI for switching AI/strategy.
  - `Tooltip.js` — tooltip helper used by other components.

- `src/context/GameContext.js` — context provider for game state (shared state between components).
- `src/hooks/useChessGame.js` — custom hook that likely contains main game loop logic and interfaces with engine.
- `src/logic/` — core chess logic and evaluation:
  - `chessEngine.js` — move generation and rules enforcement.
  - `evaluation.js` — static/evaluation heuristics for AI.
  - `threatShieldCalc.js` — helper for threat calculation.

- `src/styles/` — project CSS files (App.css, Board.css).
- `src/utils/helpers.js` — miscellaneous helpers used across the app.

Files to inspect first for reported problems

- `src/logic/chessEngine.js` — engine correctness, illegal moves, check detection.
- `src/hooks/useChessGame.js` — state transitions, side effects, timers.
- `src/components/Board.js` and `Square.js` — rendering issues and event handling.
- `src/context/GameContext.js` — context updates and stale state bugs.

How to run (Windows PowerShell)

```powershell
# install dependencies
npm install

# run in development (hot reload)
npm start

# run tests
npm test

# build production bundle
npm run build
```

Notes & suggestions

- Add unit tests near the logical modules (e.g., a `__tests__` folder or `*.test.js` files next to `logic/` files).
- Consider adding ESLint/Prettier or a basic GitHub Actions workflow that runs `npm test` and `npm run build`.
- Keep `Board` and `chessEngine` small and well-tested — most bugs will surface there.
